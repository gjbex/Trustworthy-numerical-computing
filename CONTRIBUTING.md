# Contributing

Contributions are welcome.

Please use the following workflow:

1. Open an issue or discuss the proposed change with the maintainer.
1. Create a branch for your work.
1. Keep changes focused on one topic.
1. Update documentation when examples, setup instructions, or schedules change.
1. Submit a pull request.


## Training Material

When contributing examples or exercises, make sure they are easy for
participants to run and that required software, data, and commands are
documented close to the files that need them.
